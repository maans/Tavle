# Min undervisningstavle

En enkel, lokal webapp til at bygge interaktive undervisningstavler direkte i browseren.

Appen kan bruges til korte oplæg, klasseaktiviteter, gruppearbejde, afstemninger, lodtrækning, ordskyer, timere og visuelle tavler med tekst, billeder, video, links og PDF.

## Sådan bruges appen

Åbn `index.html` i en browser, eller læg filen på GitHub Pages.

Alt arbejde foregår lokalt i browseren. Der kræves ingen login, server eller database.

## Værktøjer

Du kan indsætte:

- tekst
- YouTube-video
- tegning ovenpå tavlen
- lykkehjul / lodtrækning
- grupper
- ordsky
- afstemning
- timer
- billede
- link
- PDF
- baggrund
- globalt ur

## Tavler

Du kan have flere tavler i samme fil og skifte mellem dem med pilene. Det gør det muligt at lave et helt undervisningsforløb med én tavle pr. aktivitet.

## Redigering og præsentation

I redigeringstilstand kan du flytte, rotere, ændre og oprette widgets.

I præsentationstilstand skjules redigeringsgrej, så tavlen er mere rolig at bruge foran elever.

## Fokus

Fokus kan fremhæve én widget og dæmpe resten. Det er nyttigt, når klassen kun skal se ét element ad gangen.

## Backup

Brug `Mere → backup` til at gemme eller åbne tavlefiler.

Det anbefales at gemme en tavlefil, når du har lavet noget, du vil bruge igen eller flytte til en anden computer.

## Privat og lokalt

Appen gemmer som udgangspunkt data i browserens localStorage. Indholdet sendes ikke til en server.

Ved brug af YouTube-videoer og eksterne links åbnes eller indlæses indhold naturligvis fra de pågældende tjenester.

## Tip

Lav én tavle pr. aktivitet, og brug pilene til at skifte mellem tavlerne i undervisningen.
