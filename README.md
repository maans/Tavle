# Interaktiv Tavle

En enkel, browserbaseret tavle til undervisning – samlet i én HTML-fil.

## v82

Værktøjslinjen er gjort smallere.

Direkte på værktøjslinjen:

- Tekst
- Video
- Tegn
- Hjul
- Grupper
- Ordsky
- Afstemning
- Timer
- Mere
- Backup

Under **Mere**:

- Billede
- Link
- PDF
- Baggrund
- Grid
- Skjul
- Linje

Derudover vises teksten **Resultater skjult** ikke i præsentationstilstand.
