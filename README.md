# Interaktiv Tavle


## v144 REN

Bygget fra v144-basen med minimal patch: backup er tilføjet direkte til den faktiske Mere-menu (`data-more-tool`) og hjælp lytter nu både på `data-tool` og `data-more-tool`. Hovedtoolbar er kompakt og backup skjules derfra.


## v144

`?`-knappen kalder nu den eksisterende `showQuickHelp()` direkte via appens egen `handleTool(t)`. Tidligere eksterne hjælp-overlay/listeners er fjernet.


## v144

Hjælpemodalen er opdateret til en FAQ-struktur med klikbare spørgsmål. Den beskriver aktuelle funktioner: widgets, præsentation, fokus, lag, tegning, hjul/lister/ordsky, afstemning, backup, browserzoom og værktøjslinje.


## v144

Hjælpen er slanket: gentagelser og irrelevante FAQ-punkter er fjernet. Modalen er gjort scroll-sikker på små skærme/iPad. Der er tilføjet en enkel tip-linje nederst som forberedelse til senere 'tip of the day'/sidevisning.


## v144

Afstemningshjælpen er rettet: fokus er nu på den didaktiske overvejelse om, at synlige live-resultater kan påvirke elevernes stemmer, ikke på redigeringsknapper.
