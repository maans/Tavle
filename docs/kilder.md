# Kildeoversigt

## Nordisk mytologi

Spørgsmålene i temaet Nordisk mytologi er kontrolleret mod følgende kilder:

* Danmarkshistorien / Lex: Artiklen om nordisk mytologi beskriver Asgård, Midgård, Udgård, Valhal og Yggdrasil samt rollerne for Odin, Thor, Frey, Freyja og Loke.
* Lex.dk: Artiklen om Heimdal beskriver Heimdal som asernes vogter og nævner Bifrost, Guldtop og Gjallarhorn.
* Lex.dk: Artiklen om Odin beskriver Odin som en af de vigtigste guder i nordisk mytologi og knytter ham til Sleipner, Valhal, kongemagt, krig, runer og digtekunst.

## Øvrige temaer

De øvrige temaer er oprettet som struktur og placeholders. De bør først udgives som færdige spil, når spørgsmålene er udarbejdet og faktatjekket mod relevante kilder, fx Lex.dk, Den Store Danske, museer, universiteter, myndigheder og andre fagligt pålidelige kilder.
